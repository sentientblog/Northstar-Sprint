# Northstar Support Deflection MVP — Project Board

> Project: Northstar Retail Co. — Support Deflection MVP
>
> Goal: Build a simple chatbot MVP that reduces manual support handling
> for at least two repetitive ticket categories:
> 1. Order Status
> 2. Returns & Refunds
>
> Board rules:
> - Every task must be ≤4 hours.
> - Every task must have one clear owner.
> - Every task must have a priority.
> - Every task must have a single-sentence, checkable Definition of Done.
> - Work status must be updated on the same day the work occurs.
> - Commits must follow: `<type>: <what changed> - <why it matters>`.
> - "wip" and "updates" are not acceptable commit messages.
> - Work must be traceable from board task → contributor → commit/edit → artifact.
> - Tasks should be split further if their work exceeds 4 hours.
